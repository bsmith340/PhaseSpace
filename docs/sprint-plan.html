06 · SEO playbook

How BCS Academy gets found

SEO for a small, focused board comes down to three things: Google can read every page, every page answers a real search, and other sites point to you.

1 · Technical

  • Real URLs, no # routes
  • Static HTML for each page
  • sitemap.xml, robots.txt
  • Unique <title> and description
  • Canonical, Open Graph, JSON-LD
  • Core Web Vitals "good"
  • HTTPS on your own domain

2 · Content

  • One page per unit and topic
  • 150–300 words of intro text
  • A FAQ that answers real questions
  • Internal links: unit → topic → lab
  • Descriptive headings (H1, H2)
  • Updated each term; dates shown

3 · Authority

  • School websites and teachers linking
  • Video descriptions linking back
  • A Google Business Profile (tutoring)
  • Mentions in NI student groups
  • Never buy links

Page title formula and keyword map

Titles follow "[Unit] [subject] revision: [what's in it] | BCS Academy". The searches below are examples; find real ones in Search Console once data arrives.

Weekly Search Console routine (10 minutes, Sundays)

  1. Pages → Not indexed: fix the top reason first.
  2. Performance → Queries: find searches with impressions but few clicks, and rewrite those pages' titles.
  3. Queries ranked 8–20: add a paragraph or FAQ to that page. These are the quickest wins.
  1. Core Web Vitals: anything not "good" goes on next week's list.
  2. Links: note any new site linking to you and thank them.
  3. Write it down in the scorecard: impressions, clicks, average position.

Expect

A new site can take anywhere from a few days to several weeks to be crawled and indexed, and Google gives no fixed timeline. Submitting a sitemap and using URL Inspection helps. Rankings build over months, which is why the technical work goes first.

10 · Risks and rules

What could go wrong, and the rules that prevent it

RiskOddsPrevention
The sprint overruns into study timeHighHard stop at 45 minutes; buffer days; carry tasks forward, never stay up.
Google doesn't index pagesMediumReal URLs, pre-rendered HTML, sitemap, URL Inspection; fix Search Console errors weekly.
Site suspended for hosting limitsMediumMove to Cloudflare Pages; smaller per-page files; fewer manual deploys.
Losing the codeMediumFix GitHub on Day 1; every change pushed; keep the latest zip offline.
A content error embarrasses youMediumError button, teacher spot-checks, fixes within 24 hours, public log.
Rebrand confuses existing usersLowRedirect every old address; one notice saying "BcsMaths is now BCS Academy".
Copyright complaint over spec quotesLowLink to CCEA's papers; ask CCEA before charging for anything that quotes the spec.
Fake-review or claims breachLowOnly genuine reviews (banned since April 2025); never promise grades.

Ten rules for the sprint

  1. 45 minutes. Stop on time.
  2. Ship every day, even if it's small.
  3. Test on a phone before you push.
  4. One task per day. No side quests.
  5. If it doesn't help Google, speed or trust, it waits.
  1. Every fact on a landing page is checked.
  2. No new content until v1.0 ships.
  3. Log every day, good or bad.
  4. Real students beat your own opinion.
  5. Exams first, always.
